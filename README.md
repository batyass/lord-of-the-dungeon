# Lord of the Dungeon

2D Tug-of-War strategy game developed in **Godot 4.7.2 Forward+**. Play as the Dungeon Master defending against invading human and divine heroes across a 3-lane battle axis.

## Features
- **3-Lane Tactical Combat:** Dynamic depth-sorted battling across Upper, Middle, and Lower road lanes with pixel-accurate road calibration.
- **Dynamic Campaign:** 3 distinct levels (Hell, Earth, Sky) with animated backgrounds and progressive waves.
- **Smart Spawning AI:** Competitive unit placement based on threat detection and distance to the player base.
- **Looping Soundtracks:** Custom level-specific BGM tracks with seamless crossfading and sound effects.
