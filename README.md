# Lord of the Dungeon

Le Boss décide de sortir de son donjon pour étendre son territoire jusqu'au ciel. Ainsi, les aventuriers puis les dieux envoient des troupes pour stopper son avancée. Pour valider un niveau, le Boss doit repousser l'ensemble des vagues ennemies, qui durent un certain temps sans que son donjon ne soit détruit. ( points de vie arrivant à 0 ). Pour ce faire, il fait spawn des sbires attaquant les aventuriers et défendant le donjon.
